# UK interface refinement — v6
A targeted refinement, not a rebrand. The existing navy/teal/editorial serif identity, research data, all deep links, saved items, comparisons, quizzes, application tracker and India entry are preserved.

## Design rationale
- Visual hierarchy, grouping and progressive disclosure: Nielsen Norman Group, https://www.nngroup.com/articles/principles-visual-design/ and https://www.nngroup.com/articles/progressive-disclosure/
- Consistent spacing, responsive typography and semantic layouts: GOV.UK Design System, https://design-system.service.gov.uk/styles/spacing/ and https://design-system.service.gov.uk/styles/type-scale/
- Productive typography for data-rich interfaces: IBM Carbon, https://www.carbondesignsystem.com/building-blocks/foundations/typography/overview
- Explicit applied filters: Baymard, https://baymard.com/research-articles/how-to-design-applied-filters
- Focus, reflow, contrast, target size: WCAG 2.2, https://www.w3.org/TR/WCAG22/

Compact masthead, lighter editorial introduction, search before reading desk, grouped navigation with a single current item, bounded overview previews and explicit more controls; search and direct record links retain full access. Date formatting in UK style. Status is not conveyed by colour alone. Accessible native controls, visible focus, mobile section menu and non-obscuring scroll padding. Scrollable desktop rails, no fixed-height content clipping. No third-party fonts, trackers or runtime packages added. Standalone dossiers use the same stylesheet.

## Verification
Browser smoke tests exercise overview counts, more/reset, applied filters, mobile section navigation, multiple viewport widths and pre-existing functionality. Production browser smoke verifies the served homepage and standalone detail pages. These checks do not constitute a full accessibility audit or human visual review.

Pull-request verification captures desktop and mobile screenshots as review artifacts. Mobile closed-menu label reflects the selected workspace.

Second visual pass: more compact desktop search toolbar, mobile filters behind a labelled toggle, lead-story treatment, four immediately visible calendar items with all other dates available through native disclosure. Reviewed screenshots generated by Chromium.
